# Atlas omega independence audit

The frozen Atlas uses perturbation, alpha, resolution and algorithm families only. No omega or temporal-coupling variation appears in its config, manifest or family list; Round20 postdates it. Omega sensitivity is therefore a held-out sensitivity axis / independent axis of sensitivity for the pre-existing Atlas states, not statistical out-of-sample validation.

| Component | Used | Contains omega variation |
|---|---:|---:|
| perturbation | True | False |
| alpha | True | False |
| gamma_resolution | True | False |
| algorithm | True | False |
| k_or_edge_rule | False | False |
| representation | False | False |
| omega_or_temporal_coupling | False | False |
| Round20 | False | True |
