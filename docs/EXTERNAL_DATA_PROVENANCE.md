# External data provenance

Source: the public BDMO-derived publication [Муниципальная статистика России с 2005 года](https://tochno.st/datasets/bdmo), published by «Если быть точным» from Rosstat БД ПМО. The locally preserved archive inventory, URLs, retrieval timestamps and SHA-256 values are `outputs/final_competition_upgrade/external_validation/source_manifest.csv`. Citation: Муниципальная статистика России с 2005 года // Росстат; обработка: Если быть точным, 2025.

The publisher page did not state a machine-readable reuse license at retrieval; `not stated on publisher dataset page at retrieval; reuse terms require publisher verification`. Original ZIPs remain in `data/external/raw/`; processed 2024 tables preserve BDMO's stable OKTMO fields and never alter the SberIndex clustering.

The official SberIndex directory, ["Данные о границах и преобразованиях муниципальных образований"](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities), is preserved independently in `data/external/raw/sberindex_municipality_directory/`. It is licensed CC BY-SA 4.0. The 25-Oct-2024 publisher archive has SHA-256 `319ed22684b77716641bc15b61f7325adc44e9fc47e9be2973d88412d27d21f5`; its source and extraction manifest are `outputs/final_competition_upgrade/external_validation_sberindex_directory_20261006_r2/source_manifest.csv`.

The official directory contains `territory_id`, versioned municipality names, region codes and OKTMO. However, a lineage audit of the 1,904-municipality reference panel and its supplied raw `spending.csv.zip` found only the textual `mo` field: no `territory_id`, municipality ID, region, OKTMO or retained raw-to-reference mapping. Accordingly the directory does **not** authorize a reference-side match on its own. Name-only and fuzzy matches remain prohibited. The complete gate decision is recorded in `outputs/final_competition_upgrade/external_validation_sberindex_directory_20261006_r2/CROSSWALK_AUDIT.md`.

On 2026-10-05, the official SberIndex [Data → Sense municipal-data release](https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim) was retrieved independently. The untouched archive is `data/external/raw/sberindex_data_sense/hackathonlicence_20251018.zip` (SHA-256 `a9f932ff4096a7df797d1547987937f34d3995ac445b4748177114488d12b010`, CC BY-SA 4.0). It contains an official `consumption.parquet` with `territory_id`, 303,126 records, the six reference categories, and Jan-2023–Dec-2024. The package has only consumption, market-access, connection, and methodology files; it does not contain BDMO measures.

The standalone lineage gate is recorded in `outputs/final_competition_upgrade/data_sense_lineage_20261006_r3/`. It generated candidates strictly from an exact 24-month × six-category value fingerprint—before and without names—and independently confirmed equality of the complete identifier-free value multiset. All 1,904 strict reference trajectories had a unique official candidate. The separate directory compatibility check retained 1,903 as `VERIFIED_DATA_LINEAGE_MATCH` and held one `CONFLICT_DIRECTORY_NAME_NOT_EQUAL`; that held row is deliberately not usable for downstream BDMO matching. No BDMO join has been run from this source because the reference-to-ID gate is not complete and no documented 11-character-directory-OKTMO to 8-character-BDMO transformation has been established.
