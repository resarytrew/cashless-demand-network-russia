# Result Interpretation Rules

## Preferred terminology

Use:

- profiles of local cashless consumer demand;
- network communities;
- candidate profile;
- subtype;
- broad macroprofile;
- overlapping network regime;
- boundary/refinement population;
- reference specification;
- robustness / sensitivity / retention.

Avoid:

- economic type / type of economy as a universal label;
- proven archetype;
- optimal parameters;
- externally validated clusters;
- causal diffusion unless separately identified.

## Separate evidence axes

A profile can simultaneously have:

- strong internal cohesion;
- weak feature separation;
- high temporal persistence;
- poor boundary stability;
- strong spatial autocorrelation;
- weak beyond-context compactness.

Do not collapse these into one score or ranking.

## Null-model interpretation

Compactness ratio lower than 1 means the observed set is more compact than its matched null. Treat effect size as primary. A small p-value with ratio near 1 is not a large substantive effect.

Matched nulls answer only the dimensions they preserve. Admin-form matching does not control density; spatial blocks do not by themselves control population/urbanization; continuous residualization changes the estimand.

## Retention interpretation

Retention/recall measures how much of an original profile stays together in a best-matching new community. Precision and Jaccard are required to distinguish a stable core from a merged/broadened community.

High retention + low precision means the original core survives inside a larger merged community; it does not mean the exact boundary is stable.

## Temporal interpretation

Few switches can result from high temporal coupling. Temporal persistence is not independent evidence of feature-space separation.

## Status updates

New tests should update claims with one of:

- strengthened;
- unchanged;
- weakened;
- rejected / no longer supported;
- unresolved.

Do not manufacture a winner among A–G.
