# Переработка лендинга: 8 октября 2026 года

## Задача и принятые решения

Значительная переработка визуальной подачи существующего сайта без изменения
исследовательских результатов. Рассказ читается прокруткой; управление остаётся
доступным для самостоятельного изучения. По уточнению пользователя зелёная основа
заменена графитовой, с молочно-белым текстом и сдержанными голубыми акцентами.
Цветовая маркировка научных профилей сохранена.

Визуальный подход: картографическое издание, крупная кириллическая типографика,
открытые композиции вместо однотипных скруглённых карточек. Выразительность — 8,
интенсивность движения — 5, плотность — 4. Существующие местные шрифты и средства
визуализации сохранены, новых внешних зависимостей нет. Изображения карт строятся
по геометрии и сохранённым результатам, а не по сгенерированным иллюстрациям.
Русская пунктуация, включая необходимое тире, имеет приоритет над универсальными
стилистическими ограничениями навыка оформления.

## Содержание и прокрутка

- Новый первый экран «У спроса своя география» сохраняет масштаб выборки и периода.
- Добавлены четыре картографические сцены: Казань, Магнитогорск, Норильск и Якутск.
  Прокрутка меняет выделенные связи в обоих направлениях. На телефоне каждая сцена
  содержит свою карту; закреплённая панель не перекрывает текст.
- Сравниваемые пары, показатели первой карты и состав спектра меняются при прокрутке.
- Семь последовательных портретов раскрывают основные характеристики всех профилей.
  Исходные подробные карточки, сравнения, карта, поиск, история, выводы, ограничения,
  методология и ссылки на материалы сохранены. Команды проверки доступны в раскрываемом
  блоке. Основной рассказ не требует нажатия на кнопки.
- Пояснения и подписи увеличены; основные новые абзацы имеют размер 17–18 пикселей,
  подписи карт — 14 пикселей. Поддержаны клавиатурная навигация и сокращение движения.

## Происхождение графа

`scripts/build_landing_network.py` переносит сохранённые направленные связи с тремя
ближайшими соседями из
`outputs/round23_economic_mechanisms/network_neighbor_geography_directed.csv`.
Экспорт содержит 5 614 отношений. Это часть связей, а не полный граф. Географические
расстояния и веса копируются без пересчёта. Имена сопоставляются с идентификаторами
существующего `site/data/research.json`. Для обзорного фона применяется фиксированный
шаг отображения из `configs/landing_network.yaml`; он не меняет исследовательский граф.

`site/data/network.json` содержит происхождение данных, контрольные суммы источника,
муниципалитетов и конфигурации, версию Python/PyYAML и исходный коммит. Случайные
выборки и новые расчёты исследовательских групп не выполняются. Подписи прямо
отличают сходство расходов от денежных потоков и маршрутов покупателей.

Научные статусы A–G, исходная спецификация, результаты предыдущих раундов и
численные данные сайта не изменялись в рамках этой переработки. Новый раунд
научных свидетельств не создавался: это изменение представления сохранённых данных.

## Проверка

- Полный набор Python: **153 проверки пройдены** (`PYTHONPATH=src`).
- Полный набор браузерных сценариев: **20 проверок пройдены**, Microsoft Edge,
  один процесс выполнения. После последних уточнений подписей повторно проверены
  четыре затронутых сценария.
- Проверки текущих артефактов и структуры репозитория: **PASS**.
- Просмотрены снимки первого экрана, карт, портретов и мобильного рассказа.
  Снимки находятся в `outputs/landing_design_20261008/`.
- Проверены размеры 390, 768, 1280 и 1440 пикселей, отказ загрузки данных, повторная
  загрузка, поиск, слои и месяцы карты, сохранение численных значений и статусов.

Первый запуск Python без пути к `src` завершился ошибкой импорта; запуск с путём
прошёл полностью. Параллельный запуск браузерных проверок дал нестабильные загрузки;
полный последовательный запуск прошёл. При визуальной проверке исправлены
перекрытие мобильного текста закреплённой картой, сжатие первого холста и сдвиг
переходов из-за изменения высоты пояснения спектра.

Сборка: `npm run build:site`. Она также обновляет новый экспорт связей и публикует
одинаковые материалы по трём локальным адресам: `/`, `/atlas/`, `/site/`.
Исследовательские расчёты при сборке не запускаются.
