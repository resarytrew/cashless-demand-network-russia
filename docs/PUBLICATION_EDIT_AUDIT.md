# Редактура публичного слоя: состав изменений и проверка смысла

Это журнал редакторской работы, а не новый научный результат. Входное вычислительное состояние — коммит `3c988699118f7718e1ea1bfeed8c111d157e8de9`, вошедший в main через `2dcef7c`. Объём задачи: сделать исследование понятным конкурсному жюри, сохранив расчёты и ограничения.

## Публичные документы

- `README.md` полностью переписан: вопрос → данные → сеть → проверка устойчивости → изменение интерпретации → внешние наблюдения → ограничения. Около 1 450 слов вместе с таблицами и ссылками; при 150–200 словах в минуту это примерно 7–10 минут. Это оценка объёма чтения, не результат пользовательского теста.
- `docs/public/METHODOLOGY.md` объясняет каждый шаг в порядке «Зачем / Простыми словами / Технически», затем даёт формулы и ссылки на код.
- `docs/RESULTS.md` отдельно раскрывает D–F–G, A, неопределённый Хабаровск, B–E, C и условную временную устойчивость.
- `docs/LIMITATIONS.md` собирает ограничения показателей, аддитивности, выборки, времени, экономической интерпретации и воспроизводимости.
- `docs/TECHNICAL_APPENDIX.md` сохраняет доступность точных определений, порогов, команд и внутренних документов.

Пользователь выбрал путь `docs/public/METHODOLOGY.md`: в Windows `docs/METHODOLOGY.md` конфликтует с историческим `docs/methodology.md`. Старый файл не переименован и не изменён. Прежний README сохранён побайтово в `docs/PUBLICATION_BASELINE_README.md`, как технический архив, не новая конкурсная страница.

## Смысловые уточнения без изменения результата

1. p≈0,089 описывается как результат отдельной регрессии с ковариатами, не multiple-testing correction. В расчётах нет такой поправки.
2. Слабая связь зарплаты с населением внутри A не превращена в доказательство независимости от размера. «A — просто крупные города» помечено как неустановленное сведение, не как полностью исключённая роль населения.
3. Вместо «высокодоходного» режима говорится об измеренной зарплатной и инвестиционной интенсивности. Доходы домохозяйств и добывающий механизм не установлены.
4. Временная устойчивость оговорена как условная и ретроспективная. Она не доказывает возможность прогнозирования.
5. B/E не объявлены внешне подтверждёнными; C остаётся контекстным и неразрешённым. F — переходная интерпретация с региональными оговорками, не причинная траектория.
6. Группы A–G не отождествлены со всеми сообществами сети или семью универсальными экономическими типами.

## Техническое изменение отдельно от публичного текста

Пользователь отдельно разрешил адаптацию `.github/workflows/verify.yml`. Причина: исторический общий manifest содержит старые хеши README и workflow. Сам manifest и verifier неизменны.

CI проверяет текущий набор тестов, экспортирует текущий коммит во временный каталог и заменяет **только README и workflow** их прежними копиями, чьи SHA256 проверяются по старому manifest. Вычислительный код, входы, outputs и manifests в этой копии остаются из текущего коммита и проходят исходный verifier. Рабочее дерево не подменяется. Прежний workflow побайтово сохранён как `docs/PUBLICATION_BASELINE_VERIFY.yml`.

Исследовательский код, скрипты, тесты, научные конфигурации, исходные данные и все evidence-артефакты не меняются. CI — единственная разрешённая техническая адаптация, и её diff показывается отдельно до финального коммита.
